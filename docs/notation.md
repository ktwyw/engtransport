Conventions:

* SI units throughout. Temperatures in the text are often given in °C; the code works in
  kelvin.
* Equations are numbered by chapter, (1.1), (1.2), …; figures likewise.
* A result is "checked" when it has been compared with an exact solution or with an
  independent numerical solution accurate enough for the comparison, and the size of
  the difference is printed in the notebook.
* Property values come from `engtransport.properties`: short formulas fitted to the
  international reference equations, with the largest fit error recorded
  (`scripts/fit_properties.py`).
